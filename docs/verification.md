# Проверка

Задача не закрыта, пока не названы результаты проверок по затронутым требованиям. Каждый пункт получает один статус:

- **выполнено** — команда или сценарий запущены, результат получен;
- **не выполнено** — приведи вывод;
- **не проверено** — назови причину.

## Что проверять по типу изменения

| Изменение | Проверка |
| --- | --- |
| Исходник спеки, извлечения | `python3 scripts/sync_spec.py --check` → OK. Новый раздел без записи в `EXTRACTS` валит скрипт. |
| Реестр и ID | Новые ID не совпадают с существующими, номера в диапазоне идут без пропусков. См. [structure](spec/structure.md). |
| ADR | Статус соответствует решению пользователя. Все ADR есть в [индексе](adr/index.md). |
| Код (с этапа E0) | Тесты для затронутых AC. Например: AC-003 (повторный импорт без дублей), AC-006 (частичный ChangeSet отклоняется целиком), AC-015 (ложный SHA отклоняется), AC-019 (ПСИ без выдуманных порогов). |
| Инварианты | NFR-001, NFR-002, NFR-019 — негативные тесты обязательны, не только позитивные. |
| Скиллы (с этапа E2) | Eval-кейсы по AC-011 (отказ draft-ключу), AC-014 (предложения не повышают confirmed), AC-024 (инструкция из источника не выполняется), AC-029 (ответ с AgentRun и citations). |
