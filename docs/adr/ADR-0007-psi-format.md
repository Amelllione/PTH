# ADR-0007 — ПСИ P0

- Статус: Proposed (рабочий вариант, ждёт решения пользователя)
- Дата: 2026-10-04
- Supersedes: —
- Связанные требования: [DEC-07](../spec/defaults.md)

## Контекст

ПСИ P0. Вопрос раздела 20 спеки, DEC-07.

## Рассмотренные варианты

1. Рабочий вариант: Versioned model + Markdown/JSON/CSV.
2. Альтернатива: Корпоративный DOCX export — отдельный шаблон/adaptor.

## Решение и причины

Для старта разработки взят рабочий вариант: Versioned model + Markdown/JSON/CSV. Спека предлагает его как исходный; это предложение, а не согласованное решение.

## Последствия

Корпоративный DOCX export — отдельный шаблон/adaptor.

## Условия пересмотра

Пересмотреть после решения пользователя по документу или при изменении нагрузки, состава команды, клиентов или Git-платформы.
