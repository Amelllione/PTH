# ADR-0008 — Размер команды

- Статус: Proposed (рабочий вариант, ждёт решения пользователя)
- Дата: 2026-10-04
- Supersedes: —
- Связанные требования: [DEC-08](../spec/defaults.md)

## Контекст

Размер команды. Вопрос раздела 20 спеки, DEC-08.

## Рассмотренные варианты

1. Рабочий вариант: Один владелец, несколько проектов, scoped service accounts.
2. Альтернатива: Массовая команда требует дополнительных collaboration/SLA целей.

## Решение и причины

Для старта разработки взят рабочий вариант: Один владелец, несколько проектов, scoped service accounts. Спека предлагает его как исходный; это предложение, а не согласованное решение.

## Последствия

Массовая команда требует дополнительных collaboration/SLA целей.

## Условия пересмотра

Пересмотреть после решения пользователя по документу или при изменении нагрузки, состава команды, клиентов или Git-платформы.
