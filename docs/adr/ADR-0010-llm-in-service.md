# ADR-0010 — LLM внутри сервиса

- Статус: Proposed (рабочий вариант, ждёт решения пользователя)
- Дата: 2026-10-04
- Supersedes: —
- Связанные требования: [DEC-10](../spec/defaults.md)

## Контекст

LLM внутри сервиса. Вопрос раздела 20 спеки, DEC-10.

## Рассмотренные варианты

1. Рабочий вариант: Нет обязательного LLM; Claude приносит proposals/findings.
2. Альтернатива: Server-side agents требуют provider routing, quotas и eval.

## Решение и причины

Для старта разработки взят рабочий вариант: Нет обязательного LLM; Claude приносит proposals/findings. Спека предлагает его как исходный; это предложение, а не согласованное решение.

## Последствия

Server-side agents требуют provider routing, quotas и eval.
