# ADR-0011 — Schema extensibility

- Статус: Proposed (рабочий вариант, ждёт решения пользователя)
- Дата: 2026-10-04
- Supersedes: —
- Связанные требования: [DEC-11](../spec/defaults.md)

## Контекст

Schema extensibility. Вопрос раздела 20 спеки, DEC-11.

## Рассмотренные варианты

1. Рабочий вариант: Фиксированный versioned набор P0, API изменения в P1.
2. Альтернатива: Полная динамическая схема в P0 усложняет migrations/UI/rules.

## Решение и причины

Для старта разработки взят рабочий вариант: Фиксированный versioned набор P0, API изменения в P1. Спека предлагает его как исходный; это предложение, а не согласованное решение.

## Последствия

Полная динамическая схема в P0 усложняет migrations/UI/rules.

## Условия пересмотра

Пересмотреть после решения пользователя по документу или при изменении нагрузки, состава команды, клиентов или Git-платформы.
