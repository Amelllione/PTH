# ADR-0006 — Формат источника P0

- Статус: Proposed (рабочий вариант, ждёт решения пользователя)
- Дата: 2026-10-04
- Supersedes: —
- Связанные требования: [DEC-06](../spec/defaults.md)

## Контекст

Формат источника P0. Вопрос раздела 20 спеки, DEC-06.

## Рассмотренные варианты

1. Рабочий вариант: Markdown/text/JSON.
2. Альтернатива: DOCX/PDF parsing существенно расширяет import.

## Решение и причины

Для старта разработки взят рабочий вариант: Markdown/text/JSON. Спека предлагает его как исходный; это предложение, а не согласованное решение.

## Последствия

DOCX/PDF parsing существенно расширяет import.

## Условия пересмотра

Пересмотреть после решения пользователя по документу или при изменении нагрузки, состава команды, клиентов или Git-платформы.
