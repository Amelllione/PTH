# ADR-0003 — Deployment

- Статус: Proposed (рабочий вариант, ждёт решения пользователя)
- Дата: 2026-10-04
- Supersedes: —
- Связанные требования: [DEC-03](../spec/defaults.md)

## Контекст

Deployment. Вопрос раздела 20 спеки, DEC-03.

## Рассмотренные варианты

1. Рабочий вариант: Self-hosted Docker Compose.
2. Альтернатива: SaaS требует tenancy, billing/операционный SLA.

## Решение и причины

Для старта разработки взят рабочий вариант: Self-hosted Docker Compose. Спека предлагает его как исходный; это предложение, а не согласованное решение.

## Последствия

SaaS требует tenancy, billing/операционный SLA.

## Условия пересмотра

Пересмотреть после решения пользователя по документу или при изменении нагрузки, состава команды, клиентов или Git-платформы.
