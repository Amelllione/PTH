# ADR-0005 — Автономность

- Статус: Proposed (рабочий вариант, ждёт решения пользователя)
- Дата: 2026-10-04
- Supersedes: —
- Связанные требования: [DEC-05](../spec/defaults.md)

## Контекст

Автономность. Вопрос раздела 20 спеки, DEC-05.

## Рассмотренные варианты

1. Рабочий вариант: Принятый import scope и delegated tasks без повторных подтверждений; новые решения по policy.
2. Альтернатива: Более строгий/свободный режим меняет capabilities и UI review.

## Решение и причины

Для старта разработки взят рабочий вариант: Принятый import scope и delegated tasks без повторных подтверждений; новые решения по policy. Спека предлагает его как исходный; это предложение, а не согласованное решение.

## Последствия

Более строгий/свободный режим меняет capabilities и UI review.

## Условия пересмотра

Пересмотреть после решения пользователя по документу или при изменении нагрузки, состава команды, клиентов или Git-платформы.
