# ADR-0012 — Retention исходников/кода

- Статус: Proposed (рабочий вариант, ждёт решения пользователя)
- Дата: 2026-10-04
- Supersedes: —
- Связанные требования: [DEC-12](../spec/defaults.md)

## Контекст

Retention исходников/кода. Вопрос раздела 20 спеки, DEC-12.

## Рассмотренные варианты

1. Рабочий вариант: Исторические revisions и источники сохраняются; code anchored в Git.
2. Альтернатива: Изменение хранения влияет на replay/restore и access.

## Решение и причины

Для старта разработки взят рабочий вариант: Исторические revisions и источники сохраняются; code anchored в Git. Спека предлагает его как исходный; это предложение, а не согласованное решение.

## Последствия

Изменение хранения влияет на replay/restore и access.

## Условия пересмотра

Пересмотреть после решения пользователя по документу или при изменении нагрузки, состава команды, клиентов или Git-платформы.
